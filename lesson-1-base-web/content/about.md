---
title: "Путь одного запроса"
---

Ты открыл эту страницу. Что произошло:

1. Браузер разобрал адрес `http://localhost:1313/about/` на части:
   протокол `http`, хост `localhost`, порт `1313`, путь `/about/`.
2. Определил IP хоста: `localhost` → `127.0.0.1`.
3. Открыл TCP-соединение на `127.0.0.1:1313` — туда, где слушает сервер.
4. Отправил `GET /about/ HTTP/1.1` и следом заголовки (`Host`, `User-Agent`, `Accept`, куки).
5. Сервер нашёл нужный файл и ответил: `HTTP/1.1 200 OK`, заголовки, пустая строка, тело.
6. Браузер начал разбирать HTML, увидел `<link>` и `<script>` — и отправил **ещё запросы**:
   за нашим CSS, JS, логотипом, за Bootstrap и шрифтами на чужие серверы.
7. Собрал всё вместе, нарисовал страницу, выполнил JS.

Одна страница — это не один запрос, а десяток. `F12` → **Network** → перезагрузи.

То же самое из терминала:

```bash
curl -I http://localhost:1313/about/    # только заголовки
curl -i http://localhost:1313/about/    # заголовки + тело
curl -v http://localhost:1313/about/    # весь диалог: > отправили, < получили
```

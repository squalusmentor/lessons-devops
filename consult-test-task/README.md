## До встречи

Попроси менти заранее, чтобы не тратить время консультации на скачивание:

- проверить, что Docker работает из WSL: `docker run --rm hello-world`
- поставить minikube, kubectl, helm и сделать `minikube start` по файлу 01
- скачать базовый образ для пункта 4: `docker pull registry.access.redhat.com/ubi7/ubi:7.7`
- решить, где будет LLM: виртуалка с 8 ГБ памяти или прямо WSL. Qwen3-4B нормально работает на CPU

## План на час

| Минуты | Что делаем | Что обязательно проговорить |
|---|---|---|
| 0–10 | minikube, metrics-server, визуализатор | кластер живёт в одном Docker-контейнере; kubectl и Lens ходят в один и тот же API по kubeconfig |
| 10–20 | mysql манифестами, nginx Helm-чартом | Deployment создаёт поды, Service даёт им постоянное имя; чарт это шаблон тех же манифестов |
| 20–30 | kubectl: get, describe, top, logs, exec, scale | в задании «контейнеры», по смыслу поды; «остановить» в k8s значит `scale --replicas=0` |
| 30–40 | Dockerfile на UBI, build, run, curl | в контейнере нет systemd, поэтому httpd запускаем в foreground |
| 40–50 | Linux-команды | что такое load average, PV/VG/LV, симлинк |
| 50–60 | Ollama, запрос, статистика, debug-логи | tokens/s, prompt eval и eval, почему промпты в логах это риск |

Если время поджимает, пункт 6 менти дочитывает сам: там только команды, а LLM лучше разобрать вместе

## Ошибка в формулировке задания

Пункт 3 говорит про контейнеры, а работаем в Kubernetes. Под это обёртка над одним или несколькими контейнерами с общей сетью. Команды kubectl работают с подами, а контейнер внутри пода выбирается флагом `-c`. На собесе стоит сказать это вслух: показывает, что разница понятна

## Вопросы менти в конце

Короткие, на них часто спрашивают на собесе:

| Вопрос | Ответ в одну фразу |
|---|---|
| Чем под отличается от контейнера? | под это минимальная единица k8s, внутри один или несколько контейнеров с общим IP и томами |
| Зачем Deployment, если можно создать под? | Deployment следит, чтобы нужное число подов было запущено, и пересоздаёт упавшие |
| Зачем Service? | у подов меняются IP при пересоздании, Service даёт постоянное имя и балансирует |
| Что такое Helm-релиз? | установленный экземпляр чарта со своими values и историей версий |
| Почему httpd в контейнере запускается с `-D FOREGROUND`? | контейнер живёт, пока жив главный процесс; демон уходит в фон, и контейнер сразу завершается |
| Load average 4 на 2 ядрах это плохо? | да, в очереди на CPU в среднем вдвое больше задач, чем ядер |
| Симлинк и хардлинк? | симлинк хранит путь и ломается при удалении цели, хардлинк это ещё одно имя того же файла |
| Есть ли место в LVM-группе? | столбец `VFree` в `vgs` |
| Что такое tokens/s у LLM? | скорость генерации ответа; prompt eval rate это скорость чтения промпта |

Что дальше: менти собирает вывод всех команд в один отчёт и отправляет с тестовым
